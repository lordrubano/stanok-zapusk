# stanok-zapusk

Открытое зеркало для площадки: здесь лежит **только код станка и чертёж
площадки** — то, без чего Render не соберёт службу.

Развернуть четыре станка:

    https://render.com/deploy?repo=https://github.com/lordrubano/stanok-zapusk

Ни ключей, ни настоящих документов здесь нет и быть не может: зеркало
собирается снастью с закрытым перечнем и просвечивается приманками перед
каждой выкладкой.
